# Problem

## Problem Statement

University coursework fractures across incompatible formats — handwritten lecture notes, typed essays, slide decks, readings, code — and the tools meant to unify them force a brutal trade-off: rigid, low-effort apps (Apple Notes, Reminders) can't hold it all, while flexible ones (Notion, Obsidian) demand heavy setup and a steep learning curve before they do anything useful. The result is constant tool-switching and manual drudgery: transcribing grad-program deadlines off websites into a Notion table you never reopen, screenshotting GoodNotes pages to upload to Claude one at a time, and rebuilding the same trackers by hand. No tool is *AI-native by default* — none lets you simply describe the page you need ("transcribe this meeting and tag action items," "track my grad applications") and have it built into a notebook the AI can already see in full. inkwell is an ultra-personalizable, AI-built notebook where pages are generated on demand from plain-language requests rather than assembled from templates, with the entire notebook held as live context — so the student stops being the builder and the courier between apps, and never has to leave for anything else.

## Jobs To Be Done

When I'm juggling many courses whose notes, trackers, and tasks live in mismatched formats and scattered apps, I want to describe the page I need in plain language and have an AI build it into a notebook it can already see in full, so I can keep every part of my university work in one place and never resort to another application.
